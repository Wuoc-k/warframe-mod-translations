# Warframe Mod Names

A searchable, multilingual reference for Warframe mods. Find a mod by its name in any supported language and see all available official translations alongside its complete mod card.

[Website](https://wuoc-k.github.io/warframe-mod-translations/) · [Report an issue](https://github.com/Wuoc-k/warframe-mod-translations/issues)

## Features

- Search across all imported languages, with partial-word and accent-insensitive matching.
- Compare every available translation directly in each result.
- Copy a name by clicking it or its copy icon.
- Filter by category, mod type and rarity, and sort the results.
- View full mod cards, compatibility information and links to Warframe Wiki articles.
- Minimal English interface with sticky search and a responsive layout.

## Languages

English, German, French, Spanish, Italian, Japanese, Korean, Polish, Portuguese, Russian, Traditional Chinese, Thai, Turkish, Ukrainian and Simplified Chinese.

Names are taken from official game localization data, without machine translation. Missing translations are marked as unavailable. Some official language entries use the English name.

## Data and coverage

Mod names and translations come from [Warframe Public Export Plus](https://github.com/calamity-inc/warframe-public-export-plus). Complete card images are linked through [WFCD / warframe-items](https://github.com/WFCD/warframe-items) and the [Warframe Wiki](https://wiki.warframe.com/), with original artwork from the official export CDN or [browse.wf](https://browse.wf/) as a fallback.

Data is refreshed through a daily automated workflow. Current counts, image coverage and source revisions are recorded in the [data manifest](data/manifest.json).

Coverage follows the available exports and may include historical entries. Same-name variants, such as regular and Flawed mods, remain separate. Riven entries represent base types rather than individual rolls. If a complete card cannot be verified or loaded, the site displays a labelled artwork fallback or placeholder.

The website is fully static and has no backend or database. Images are hosted externally. No analytics are used.
